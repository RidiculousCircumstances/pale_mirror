# Far Frontier pack documentation

This directory is owned by the root Far Frontier pack/deployment boundary.
It contains the active pack architecture, progression, compatibility, content
and test documentation referenced by the root [README](../README.md).
The concise root ownership map is [Repository layout](../REPOSITORY_LAYOUT.md).

Pale Mirror source, module and test documentation is intentionally scoped to
[`pale-mirror/docs/`](../pale-mirror/docs/); do not add mod implementation
documents or generated run evidence here. Pack build/runtime output belongs in
ignored task-private locations, never under `docs/`.
