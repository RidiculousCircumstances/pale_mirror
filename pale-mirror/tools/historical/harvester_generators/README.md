# Historical Harvester generators

These scripts are retained as reproducible rejected modelling experiments.
They are not inputs to the current source-pinned organic-mesh workflow and
must never overwrite a canonical Blockbench or Blender source.

- `rebuild_harvester_srp_style.mjs` — the noisy, overlapping SRP-inspired
  cuboid lattice.
- `rebuild_harvester_reference_geometry.mjs` and
  `refine_harvester_high_fidelity.mjs` — earlier scripted reconstruction
  attempts superseded by the primary-image trace and direct-v05 workflow.
- `rebuild_scythe_anatomical_cuboids.mjs` — an early cuboid anatomy pass,
  retained only as review evidence.

Run an archived script only for a specifically requested historical
investigation. Active authoring begins with the pinned reference, trace and
the current protocol documented in `pale-mirror-visuals/src/main/blockbench/harvester/README.md`.
