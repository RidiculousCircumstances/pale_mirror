# Crossbow repertoire and permanent tendencies

The accepted progression is a repertoire, not experience gain. Generated
CROSSBOW skill unlocks ordinary (0), hurried (15), precise (30), after-maneuver
(45), held (60), countershot (75), and repositioning-sequence (90) shots.
Permanent agility still changes reload; weapon skill changes aim, skill and
perception change dispersion, and perception bounds reaction time. No temporary
hunger/injury modifiers or learning system is introduced.

The shared ranged owner selects from current native sight/motion/attack facts,
existing actor-owned combat style and one bounded, encounter-scoped last launch.
Pressing favors hurried and counter shots, cautious favors accurate preparation
and longer distance, mobile favors displacement/sequence shots, and supporting
combines lateral repositioning with safer support positions. Styles grant no
skill, damage, ammunition or path permission. Existing sword behavior consumes
the same style identity; a fourth Supporting definition is explicit content.

The exact prepared intent retains technique, profile and supported origin as
well as the original body/execution, weapon, target incarnation and arrow
binding. Cancelled preparation creates no tactical credit. Only confirmed
native launch records the followup; retirement removes it. Current wire346 and
ruleset `frontier-v3-ranged-guards-r34` deliberately require a fresh disposable
world instead of guessing an old declaration's technique or origin.

Every shot completes normal reload and consumes one actual arrow and one weapon
wear through the existing durable native operation and confirmation. A precise
shot trades longer aim for narrower spread; a hurried shot does the reverse.
There is still vanilla projectile flight and collision, without guaranteed hit
or recreated projectile after recovery. Held/counter preparation has finite
reaction and bounded waiting: a missing opening falls back to an ordinary
release opportunity; persistent cover ends with positive non-emission and no
resource/wear debit. This fallback has no bonus or delayed through-cover hit.

After a confirmed shot, mobile behavior may select another known station.
The high-tier sequence explicitly selects a retreat, waits for actual movement,
then uses an ordinary shot with another full reload. A selected valid destination
survives intervening reviews. Unavailable optional relocation expires after80
simulation ticks and does not permanently block later combat. All movement uses
existing spatial claims, known multi-level geometry and UAE/navigation. These
are ordinary planned steps, not new evasion actions bypassing EVASION skill.

Combat capture now records pending/last ranged technique, attempt/preparation
and last emission tick. Verification uses the actual ranged transition/custody
path, codec and native preparation, save/load, real arrow emission/collision,
opening reaction, finite waiting, new cover and cancellation. Evidence and live
deployment identities are recorded in CONTINUITY.md. Unit/native fixture checks
are not a claim of graphical player comprehension or balance acceptance.
